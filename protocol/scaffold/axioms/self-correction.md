A system cannot verify its own foundations from outside, so frameworks silently encode unjustifiable assumptions.

Build challenge mechanisms into the framework; if they erode bad assumptions faster than the framework creates them, the system converges despite incomplete premises.

- Challenge presuppositions periodically [because assumptions drift silently without active opposition]
- Act on best current understanding, track results, fix when wrong [because the alternatives are dogmatism (never question) or paralysis (question everything)]
- A biased system can self-correct faster than it drifts [because challenge mechanisms compound corrections while drift is linear]

(Applies when evaluating whether any self-referential system — wiki, process, institution — can improve without external grounding.)

This is **Axiom zero**, referenced by the protocol (`wiki/CLAUDE.md`, line 5). It is constitutional: the governor and meta-governor ground out here. Challenge it periodically and update `last_challenged`; if a challenge produces something better, revise it.
